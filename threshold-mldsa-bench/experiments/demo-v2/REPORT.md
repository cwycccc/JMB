HTTP 字节由协调器 net.Conn.Read/Write 计数，包含请求/响应头（只计长度，不保存凭据）、JSON、Base64、分块编码等 HTTP/1.1 字节；计入所有三轮尝试，不含健康检查、公钥查询、状态查询、Abort、浏览器与后端流量，不含 TCP/IP、重传或二层头。因此这是三轮 HTTP 应用流量，不是抓包总流量。原始 Payload 仅统计节点返回的原生公开密码消息，既不等于 HTTP 字节，也不包含协调器转发给各节点的重复消息。逐样本、逐轮数据见 samples.csv。

## 安全边界与补充证据

本次性能实验未注入节点故障。节点进程中断、执行后响应超时、Abort 未确认安全停机、Combine 拒绝后全新 Round1，以及并发重复提交由真实进程集成测试单独验证，详见 acceptance-test.log；不要把门限参数检查等同于节点中断实验。

初始化通过独立 stdin 管道交付每个节点自己的份额；公开配置、日志和结果不含私钥或协调器 Token。密钥隔离结论基于初始化代码及份额测试，不宣称进行了进程内存取证。防重放和幂等均限定当前受控启动生命周期；不提供生产密钥持久化、认证用户管理或真实资金转移。
